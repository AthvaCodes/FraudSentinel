Singly Linked List (`FlagNode` in C)

Directly mirrors the C project's in-memory alert structure: flaggedHead = newNode;. When a large transaction (≥ ₹10,000) or high activity account is detected, a FlagNode is prepended in O(1) time.

Prepend: O(1) Search: O(n) Delete: O(n) Space: O(n)
Total Flagged Nodes: 0 • Memory flaggedHead Pointer: 0x0
Educational Tradeoff vs. SQLite: A linked list provides instant O(1) prepending without contiguous memory reallocation. However, it lacks random access O(1) by index, cannot perform binary search, and is volatile in RAM. SQLite complements it by persisting all historical records with durable B-tree indices on disk.

Directed Adjacency List Graph (Accounts & Transactions)

Bank accounts form vertices, and money transfers form directed weighted edges. Enables rapid graph traversal (BFS, DFS), shortest path finding, and circular smurfing / money laundering cycle detection (A → B → C → A).

Add Vertex: O(1) Add Edge: O(1) BFS / DFS: O(V + E) Cycle Detection: O(V × E)
